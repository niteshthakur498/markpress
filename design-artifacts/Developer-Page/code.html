Developer API

Integrate the industry's fastest Markdown-to-HTML conversion engine directly into your workflow. Built for high-concurrency environments and precision rendering.

Base URL: https://api.md2html.io/v1
POST /api/convert

Convert raw Markdown text to sanitized, production-ready HTML with syntax highlighting support.

Request Body (JSON)

{
  "markdown": "# Hello World\nThis is **bold** text.",
  "config": { "gfm": true }
}

Code Snippets

curl -X POST https://api.md2html.io/v1/convert \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"markdown": "# Hello"}'
POST /api/convert/file

Upload a physical .md or .markdown file for batch processing and conversion.

Form Data

# Multipart Form Data
'file': (binary stream),
'theme': 'github-dark'
